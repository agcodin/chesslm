How it plays

A language model that reads a chess position and writes a move

ChessLM is Qwen2.5-1.5B, fine-tuned with LoRA on Apple's MLX framework. It never sees a picture of a board: every position arrives as a line of text in Forsyth–Edwards Notation, and the model answers in text. Around that model sits a small search, the same selection rule AlphaZero uses, which lets it look a few moves ahead before committing.

Position

Read the board as text

The prompt is just FEN: … Best move:, about 60 tokens. An early version listed every legal move and was seven times longer; cutting it made training usable.

Moves

Score every legal move

The position is encoded once, its KV cache copied for each candidate, and all moves scored in one batch. It can never play an illegal move.

Judgement

Rate positions

A second prompt, FEN: … Eval:, makes the same model rate a position as one of 21 letters from a (lost) to u (won). One pass gives a full distribution.

Search

Look ahead, then choose

PUCT search expands the likeliest moves, rates where they lead, and plays the move it visited most. The replay above shows those visit counts.

A retrieval-augmented coach explains each move in the local app: it names the opening from Lichess's opening database, computes facts about the move (captures, checks, forks, pins, hanging pieces), retrieves matching chess principles by vector search, and has the base model explain using only those facts.

How it learned

From copying Stockfish to learning from its own games

Stage 1

Imitate Stockfish

Stockfish played itself with 15% random moves mixed in, so positions looked like imperfect human play. Each position was labelled with Stockfish's best move. Agreement with Stockfish rose from 6.5% for the untrained model to 11.75%. A 3B model did no better (9.5% against the 1.5B's 9.75% on identical data) and trained three times slower.

Stage 2

Learn to judge positions

The same positions were labelled with Stockfish's evaluation too. A 50/50 mix of move and evaluation examples dropped move accuracy to 9.0%, because the new task crowded out the old one. Keeping only 20–35% of the evaluation examples fixed it: 12.67% move accuracy and a 0.87 correlation with Stockfish's evaluations.

Stage 3

Measure real strength

Stockfish's rating limiter starts at 1320, above ChessLM, so I built a ladder beneath it: a random mover, one-ply Stockfish and Stockfish skill 0, all placed on one scale by playing each other. Blunder rate turned out to be the sharper instrument: across about 1,200 moves per run it separates versions that win/loss cannot.

Stage 4

Learn from its own games

ChessLM played 200 games, and in each position it reached, its own search's choice became the training target: expert iteration, the core idea behind AlphaZero. A second version (DAgger) used Stockfish's labels on those same positions. Expert iteration won clearly: blunders fell from 32% to about 27%, and a second, independent rating reproduced the result.

Findings

What the experiments taught

I predicted this wrong

Copying its own search beat copying Stockfish

Its search agreed with Stockfish in only 17% of positions, so I expected training on those choices to hurt. Instead the disagreements were mostly the search rejecting moves it could see were losing. The model learned to stop blundering, which matters far more at 1000 Elo than finding the exact best move.

Measurement

The obvious metric was the wrong one

Move agreement with Stockfish went down as play got better. Blunder rate, measured over a thousand moves, tracked real strength; a 30-game rating was too noisy to separate versions.

Scale

Prompt length mattered more than model size

Shortening the prompt from ~450 to ~60 tokens did more than doubling the model. And 4-bit or 8-bit compression gave no speedup: at 1.5B parameters the model isn't limited by memory bandwidth.

Search

A better evaluator isn't automatically a better search

Before expert iteration, a plain material count beat the learned evaluation inside the search. After it, the learned evaluation won clearly, plausibly because the model had been trained to agree with a search that used it.

Play it yourself

Run ChessLM on your own Mac

The trained model ships in the repository as a 21 MB adapter. The launcher downloads the base model on first run, then opens a board in your browser where you can play either colour, click a piece to see its legal moves, and read the search candidates and the coach's explanation for every reply.

Hardware
A Mac with Apple Silicon (M1 or later). The model runs on MLX, which is Apple-only.
Memory
16 GB recommended. The app loads the 1.5B model twice, once to play and once for the coach, roughly 7 GB.
Software
uv and git.
First run
A few GB of downloads (mostly the 3 GB base model), a few minutes. Later starts are much faster.
Speed
About 4 seconds per move at 16 search simulations on an M5 Pro, coach included. Deeper settings take longer.

Not on a Mac? The replay at the top of this page is a real recorded game, with the search candidates, evaluation and Stockfish's verdict for every ChessLM move.
